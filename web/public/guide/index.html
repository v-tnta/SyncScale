SyncScale は、大学の課題を S / M / L のざっくり見積もりで登録し、実際にかけた作業時間を記録していくタスク管理ツールです。 自分の取り組み方のクセに気づき、無理のない計画につなげることを目指しています。

Google アカウントでログイン → 同意書を確認して参加できます。参加は任意で、いつでも撤回できます。

FEATURES

SyncScale でできること

登録・記録・ふり返りを、なるべく手間なく続けられるように作っています。

manaba の課題を取り込み

Chrome 拡張機能から、manaba の課題名・科目名・締切をまとめて取り込めます。手入力の手間と締切の見落としを減らします。

S / M / L でざっくり見積もり

「何分かかるか」ではなく、課題の重さを S（小）・M（中）・L（大）で直感的に選ぶだけ。登録のハードルを下げます。

作業時間の記録

タイマーで計測、または後から手入力で、課題ごとに作業時間を記録。完了時にはその時のコンディションも残せます。

締切カレンダー

月・週表示で締切と作業の記録を一望。課題の重さが色で分かり、作業した日には実績のマークが付きます。

ふり返り分析

記録がたまると、自分の取り組み方を 5 つの観点で確認できます。

平均着手タイミングサイズ別の平均作業時間一夜漬け度よく作業する時間帯放置タスク

スマホでも同じデータ

iPhone アプリ・スマホのブラウザからも同じアカウントで利用でき、データは自動で同期されます。スマホアプリでは締切前の通知も受け取れます。

課題の登録

manaba を開いて、ボタンを押すだけ

Chrome 拡張機能の「課題を取得する」を押すと、manaba の課題が SyncScale に取り込まれます。新しい課題ごとに S / M / L を選べば登録完了。追加したくない課題は取り込まずにスキップできます。

ふり返り

自分の「取り組み方のクセ」が数字で分かる

記録した作業時間から、サイズごとに締切の何日前に着手しているか、実際に何時間かかっているかを集計します。「L の課題は思ったより早めに始めたほうがいい」といった気づきにつながります。

RESEARCH

研究へのご協力をお願いします

SyncScale は、タスク管理・主観的な課題の規模・実際の作業時間の記録と分析を通じて、学習プロセスの改善を支援するツールとしての有用性を検証する研究の一環として運用しています。 ふだんの課題管理に使っていただくことが、そのまま研究への協力になります。

研究期間2026年7月22日 〜 2027年2月20日
参加条件18歳以上の方。参加は自由で、参加しなくても不利益は一切ありません。
いつでも撤回できます研究期間内であれば、設定画面の「同意の撤回」からいつでも参加をやめられます。撤回すると、収集されたデータはすべて削除されます。
データの取り扱いデータは暗号化された安全なサーバーに保管し、研究目的（分析・学術論文・学会発表など）にのみ使用します。分析は個人が特定されないよう匿名化した上で行います。

記録させていただくデータ

  • Google アカウントの識別子（ログイン・本人確認のため）
  • 登録したタスクの情報（タスク名・期限・カテゴリ・ステータス・完了時のコンディション）
  • 課題の見積もり（S/M/L）と実際の作業時間
  • システムの利用状況（ログイン状況・滞在時間・各機能の使用状況）
  • 事前・事後アンケートの回答と回答状況

詳しくは、参加時に表示される研究参加への同意書をご確認ください。研究責任者: 茨城大学 鎌田 賢

HOW TO JOIN

参加の流れ

画面の案内に沿って進めるだけで始められます。初期設定は PC での操作をおすすめします。

  1. Google でログイン

    「アプリを開く」から、お持ちの Google アカウントでログインします。

  2. 同意書を確認して参加

    研究の説明を読み、内容に同意いただける場合のみ参加に進みます。

  3. 初回アンケートに回答

    研究の事前調査として、短いアンケート（Google フォーム）にご協力ください。

  4. LINE オープンチャットに参加

    連絡事項やサポート、研究に関するお知らせはオープンチャットで配信します。

  5. Chrome 拡張機能を追加PC

    manaba の課題を取り込むための拡張機能を Chrome ウェブストアから追加します。

  6. チュートリアルで使い方を確認

    実際の画面を操作しながら基本の使い方を確認したら、あとはふだん通り課題管理に使うだけです。

FAQ

よくある質問

利用にお金はかかりますか？

無料でご利用いただけます。

途中で参加をやめられますか？

はい。研究期間内であれば、アプリの設定画面から「同意の撤回」を行うことでいつでもやめられます。撤回すると、収集されたデータ（タスク・ログ・個人情報）はすべて削除されます。

Chrome 以外のブラウザでも使えますか？

アプリ本体は他のブラウザでも利用できますが、manaba から課題を取り込む拡張機能は PC 版の Google Chrome でのみ動作します。拡張機能を使わず、課題を手入力で登録することもできます。

スマートフォンでも使えますか？

はい。iPhone アプリ（App Store）またはスマホのブラウザから、PC と同じアカウントでご利用いただけます。データは自動で同期されます。

課題の内容や成績が研究者に見られますか？

収集するのは上記「記録させていただくデータ」に挙げた項目のみで、manaba 上の成績や提出物の中身は取得しません。分析は匿名化した上で統計的に行います。

問い合わせ先はどこですか？

参加後は LINE オープンチャットでサポートしています。研究そのものに関するお問い合わせ先は、同意書に記載の研究責任者・研究担当者までご連絡ください。
